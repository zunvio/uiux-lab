## What is actually shipping in 2026 (not just demos)

**Adopt**
- **Bento grids** — asymmetric CSS Grid, mixed spans, rounded tiles. Now standard for SaaS feature pages, pricing and dashboards. Risk: collapses badly on mobile and can break screen-reader reading order — design mobile + reading order first.
- **Dark-mode-first** — near-black `#050505`, elevation by lightness not shadow, one saturated accent. Shipped by Linear / Vercel / Raycast-style products.
- **Glassmorphism as accent only** — `background: rgba(255,255,255,.07); backdrop-filter: blur(12px); border: 1px solid rgba(255,255,255,.15)`. Heavy glass caused 15-30% FPS drops on mid-tier Android in field reports. Use on nav, modals, feature cards only.
- **Typographic-first / editorial** — variable fonts, type as the hero, plus a counter-aesthetic: cream background, serif headlines, warm palette for trust pages.
- **Scroll-driven animations, CSS-first** — native `animation-timeline: scroll()`, with reduced-motion fallback. JS-driven parallax hurts INP.
- **Purposeful micro-interactions + skeletons** — now baseline quality, not decoration.
- **Data storytelling** — animated, guided dashboards instead of static chart dumps.
- **Machine Experience (MX)** — semantic markup + structured data so agents/crawlers can use the page. Cheap, reversible, behind tokens.
- **Accessibility-first + calm design** — attention as a resource; accessibility as craft, not checklist.

**Test (hero / one place only)**
- Kinetic / variable typography — fights screen readers, crawlers and CLS if overused. Hero headline only.
- Liquid Glass, spatial depth, WebGL / 3D heroes — page weight + mobile GPU cost. Product showcase only, with a static fallback.
- AI-personalised layouts — cache fragmentation, LCP cost. Only with strong first-party data.

**Skip on conversion / B2B SaaS pages**
- Neo-brutalism / maximalism — WCAG contrast failures, weaker conversion. Allowed for a portfolio/brand experiment, never a checkout or signup page.
- Organic blobs as hero — recycled in trend lists, rarely ships in B2B SaaS / e-commerce.
- Neumorphism — accessibility problems, fading.
- Complex animation everywhere, infinite scroll with no end.
