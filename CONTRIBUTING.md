# Contributing

Thanks for improving the UI/UX Lab.

## Rules that keep contributions mergeable
1. **Original work only.** Do not submit code, assets or layouts copied from other sites, kits or repositories. Patterns and ideas are welcome; implementations must be your own. If you reuse open-source code, name the project and its licence in the pull request — it will be verified before merge.
2. **Single-file prototypes.** Each prototype stays one self-contained `index.html` with no external scripts, fonts, trackers or images, under 60 KB.
3. **Accessibility is a gate.** Visible focus, reduced-motion fallback, 4.5:1 body contrast, working mobile layout. PRs that regress these will be asked to fix them first.
4. **No people in visuals.** Screenshots and demos show UI, geometry, charts and text only.
5. Keep it small: one concept or one fix per PR, with a short note on what pattern it explores.

## Process
Open the PR against `main` on GitHub (the primary host; GitLab is a read mirror). Describe the change, the pattern behind it, and how you validated it.
