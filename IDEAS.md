# Ideas v1 — invented from the 2026-10-28 research
Scoring: Impact x Likelihood / Effort (1-5 each). Build in score order, one per sprint.

1. **Calm Bento SaaS (BUILT, prototype 01)** — bento feature grid + calm design: no kinetic type, generous whitespace, one accent, reduced-motion by default. Change vs trend demos: we remove the motion/glass excess that field reports blame for FPS and CLS problems. Score 20.
2. **Command Dashboard (BUILT, prototype 02)** — dark-first bento dashboard where every tile is also a graphical-first control (drag/slider/toggle directly, no prompt needed) + a command bar. Change: bento tiles are controls, not posters. Score 16.
3. **Editorial RTL Bento (BUILT, prototype 03)** — cream/serif editorial trust page, bento underneath, designed RTL-first in Arabic for the Shughlna audience (category content only, no product price/claims). Change: almost all bento references are LTR/English; this is RTL-native with logical properties. Score 16.
4. **Invoice-in-a-Bento** — for the free Invoice Generator: each bento tile is one step (items, tax, total, export) and the document preview updates live. Score 15.
5. **Trust Bento for childcare (no images)** — KidCare waitlist page using typography, checklists and geometric patterns only — proof the no-humans rule can still feel warm. Category/waitlist only, no child data, no prices. Score 12.
6. **Offline Glass** — glass nav/modal only, everything else flat; publish the performance numbers vs a heavy-glass variant as the content itself. Score 12.
7. **Skeleton-First Landing** — the loading skeleton IS the design system demo; toggle slow/fast to show perceived performance. Score 9.
8. **One-Accent Pricing** — pricing page where a single accent colour carries the recommended plan and nothing else coloured exists on the page. No real price until a brief allows one — use placeholder tiers labelled as a concept. Score 9.
9. **Data-Story Scroll (CSS only)** — scrollytelling dashboard story with zero JS, `animation-timeline: scroll()` + static fallback. Score 8.
10. **Swiss-Grid Brutalist Portfolio (experiment only)** — strict grid, thick borders, high contrast checked against WCAG; brand lane only, never conversion. Score 6.

Kill rule: a concept with no prototype engagement (repo stars/forks, post interactions, or product-team use) after 14 days and 30 impressions is archived to the graveyard note, not endlessly polished.
